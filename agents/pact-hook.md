# Pact Hook

Este archivo define las palabras clave (triggers) que activan la orquestación para la generación y validación de pruebas de contratos.

**Trigger Keywords:**
Si el usuario menciona alguna de las siguientes palabras clave en su prompt:
- `contract-test`
- `generacion de pacts`
- `pactos`
- `pact`
